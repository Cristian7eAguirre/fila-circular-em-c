Fila Circular em Linguagem C.

Cristian Escobar Aguirre.
SI 2026

Esse repositório contém a implementação prática de FILA CIRCULAR utilizando a linguagem C, aplicando os conceitos fundamentais de:
FIFO - O primeiro elemento a entrar o primeiro a sair.
Arrays e Structs - Estruturação de dados para gerenciar registros.
Operador Módulo - Essencial para esse comportamento circular dos indices dando inicio e fim.

O exercicio 1 implementa uma fila circular de numeros inteiros e gerenciados por um menu de opções, contendo inserção, remoção, lista e encerramento.
Conta com controle de limites para evitar estouro de memória.

O exercicio 2 simula um sistema de atendimento baseado em senhas e nomes. Utiliza uma struct composta por numero de senha e nome da pessoa.
A cada operação o programa exibe os indices de controle (inicio, fim e quantidade), demonstra o comportamento circular e o reaproveita a cada posição liberada no array.

Certifique-se de possuir um compilador C compativel instalado ou utilize o online.
